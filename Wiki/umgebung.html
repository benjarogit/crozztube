Troubleshooting

TLS-Fehler „wrong version number“ beim Aufruf: SSL-Vhost war nicht enabled. Fix (falls Container neu gebaut): docker exec crozztube-web a2ensite 000-default && docker exec crozztube-web apachectl graceful. Im Image-Snapshot ist das seit dem Dockerfile-Fix dauerhaft behoben (kein a2dissite mehr).
Installer/„session expired“: Cookie + X-Installer-Token gehören zusammen; Token aus der aktuell geladenen install.php nehmen (csrfToken=...). Nach Container-Rebuild neue Session holen.
CLI-Checks für Settings (in Container, ohne artisan): php -r 'require "vendor/autoload.php"; require "bootstrap/app.php"; echo json_encode(App\Support\VideoImportSettings::publicSettings());'
