5. yt-dlp Source-Resolver (Plugin) FERTIG · v0.2.4

Implementiert:
A) Direkt-URL via yt-dlp = Pflicht. Beim Import (POST /api/video-imports) wird der Job ResolveImportSource dispatcht. yt-dlp (-J, keyless) liefert Metadaten + Direkt-URL. Auswahl: HLS-Manifest bevorzugt → sonst progressive MP4.
YouTube-Sonderfall (SABR/DASH): YouTube liefert kein muxed MP4 mehr und kein Master-Manifest. Das Plugin baut deshalb ein synthetisches HLS-Master-Manifest (/api/source-resolver/manifest/{id}): es verbindet die separates Video-Playlists (144p–2160p, AVC/VP9) mit der AAC-Audio-Playlist (itag 233/234) zu einer gültigen Master-Playlist. Segmente streamen per Passthrough-Proxy (/api/source-resolver/playlist + /seg, googlevideo-Allowlist) direkt vom Original-CDN — nichts wird gespeichert oder re-gehostet, der Proxy existiert nur, weil googlevideo kein CORS sendet.

Endpoint (Plugin-Routen)Zweck
GET /api/source-resolver/status/{videoId}State für Ajax-Banner (fresh/refreshing/error, downloadable)
POST /api/source-resolver/refresh/{videoId}Refresh anstoßen (idempotent, Single-Flight)
GET /api/source-resolver/manifest/{videoId}Synthetisches HLS-Master-Manifest
GET /api/source-resolver/playlist?url=…CDN-Playlist-Passthrough + Segment-URL-Rewrite
GET /api/source-resolver/seg?url=…CDN-Segment-Streampassthrough (nur *.googlevideo.com)
GET /api/source-resolver/download/{videoId}Download-Passthrough (beste MP4); 409 bei HLS-only → Button versteckt

B) Ablauf-Refresh: TTL wird aus den expire=-Parametern der gespeicherten CDN-URLs berechnet (YouTube ~6 h). Ablauf → State stale → Reload/Watch-Seite triggert RefreshSource; Single-Flight-Lock (Cache-Lock 600 s + Dispatch-Guard 30 s) verhindert parallele Doppel-Refreshes; Refresh in einer Minute

C) Embed-Mirror-Fallback: Liefert der Resolver nichts (State error/refreshing), liefert VideoSources leer → PlayHub fällt auf YouTube-Embed zurück. Eigener Player hat mit frischer Quelle immer Priorität (Patch in app/Http/Resources/VideoResource.php).

D) Download-Button: nur aktiv, wenn downloadable=true (progressive MP4 existiert). YouTube = HLS-only → 409, Button versteckt. Passthrough mit Content-Disposition, kein Cache.

Betriebshinweise: yt-dlp ist im Image (2026.10.26) und wird vom cron-Container täglich aktualisiert (Marker /tmp/.crz-yt-dlp-last-update). Nach Plugin-Updates: php artisan queue:restart (Worker lädt Job-Klassen sonst nicht). DB-Tabelle: crozztube_import_sources (Spalten u. a. media_url, variants, audio_url, expires_at).
